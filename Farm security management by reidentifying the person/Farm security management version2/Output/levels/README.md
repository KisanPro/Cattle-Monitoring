# Farm Security Management — Multi-Level Evaluation Logs & Outputs

This directory contains evaluation records, test results, video stream captures, and face re-identification logs across the three stages of Farm Security Management deployment:

* **Level 1 — Lab Environment**: Synthetic laboratory benchmarks, feature extractor embeddings testing, face crop alignment validations, and vector database retrieval benchmarks.
* **Level 2 — Lab Real-Time Environment**: Live Edge AI inference testing on NVIDIA Jetson devices connected to real-time CCTV streams in the testing environment.
* **Level 3 — Field Real-Time Environment**: On-field commercial cattle shed and farm perimeter security deployments with multi-camera person re-identification and unauthorized intrusion alerting.
