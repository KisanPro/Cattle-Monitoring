# Integrated AI-Based Cattle Health Monitoring System

## Overview
The **Integrated AI-Based Cattle Health Monitoring System** connects and synthesizes data generated by three independent mobile monitoring APKs:
1. **Cattle Vaccination Monitoring APK**
2. **Milk Production Monitoring APK**
3. **Cattle Weight Monitoring APK**

Instead of replacing the existing APKs, this system acts as a **central intelligence and integration layer** on top of them. All datasets are unified at the individual cattle level using a unique `Cattle_ID` (e.g., `KA-1989` — *Geetha*, *HF* breed, belonging to `8088032780_Samruddhi_Farm`).

## Example Case Study: KA-1989 (Geetha)
| Date | Cattle ID | Milk Production | Body Weight | Vaccination Status |
| :--- | :--- | :--- | :--- | :--- |
| 01-09-2026 | KA-1989 | 16.2 L | 450 kg | Up to Date |
| 02-09-2026 | KA-1989 | 15.8 L | 449 kg | Up to Date |
| 03-09-2026 | KA-1989 | 13.9 L | 443 kg | Up to Date |
| 04-09-2026 | KA-1989 | 11.5 L | 438 kg | Due Soon |

### AI Multi-Variable Assessment Output:
- **Risk Level**: `HIGH RISK` (Score: 48.0 / 100)
- **Detected Changes**:
  - Milk: `16.2 L → 11.5 L` (-29.0% drop)
  - Weight: `450 kg → 438 kg` (-2.7% loss)
  - Vaccination: `Due Soon`
- **AI Observation**: Continuous simultaneous decrease in daily milk yield and body weight indicates high risk of metabolic/infectious etiology.
- **Recommended Actions**: Check feeding behavior, perform California Mastitis Test (CMT), evaluate broad-spectrum deworming, and request immediate clinical veterinary exam.

## How to Run the System

### 1. Install Dependencies
```bash
cd backend
pip install -r requirements.txt
```

### 2. Seed Realistic Test Data
```bash
python seed_data.py
```

### 3. Run Automated Tests
```bash
pytest test_integrated_system.py -v
```

### 4. Start the Central Backend Server
```bash
uvicorn app.main:app --host 0.0.0.0 --port 5055 --reload
```
API Documentation will be accessible at: `http://127.0.0.1:5055/docs`.

### 5. Launch the Unified Health Dashboard
Open `frontend/index.html` in any web browser to explore interactive synchronized charting, live health assessment gauges, and APK data simulation.
