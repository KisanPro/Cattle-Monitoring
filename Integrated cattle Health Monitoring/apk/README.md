# KisanPro Unified Mobile Application APK

Due to GitHub's file size limitations (100 MB hard limit), the unified build APK (`KisanPro Unified.apk`, approx. 180 MB) is hosted externally rather than directly in this repository.

* **Primary Application Package**: `KisanPro Unified.apk` (~180 MB)
* **Production Release Package**: A lightweight release APK (`KisanPro_Unified_Production_v1.0.apk`, ~28 MB) is tracked and available in `Integrated Cattle Health Monitoring Codes/kisanpro_unified_app/apk/`.
