# Technology Stack

## Programming Languages
- **Dart**: 3.4.3 (Flutter Client Application)
- **Python**: 3.9, 3.10, 3.11 (Flask Gateway, FastAPI Health, PyTorch Worker, WSL2 3D Server)
- **SQL**: ANSI SQL / PostgreSQL 15 dialect / SQLite 3 dialect
- **Bash / PowerShell**: Linux daemon automation and Windows PowerShell worker execution

## Frameworks & Libraries
- **Mobile Client**: Flutter 3.22.2, Provider (State Management), ModelViewerPlus (3D GLB), FL_Chart, PDF
- **Cloud Gateway**: Flask 3.0.2, Flask-SQLAlchemy 3.1.1, Flask-JWT-Extended 4.6.0, Gunicorn 23.0.0, Boto3 1.34.84
- **AI & Deep Learning**: PyTorch 2.4.0 (CUDA 12.1+), torchvision, OpenCV 4.9, scikit-learn 1.4.1, TRELLIS.2 4B, FlashAttention
- **Milk & Health Backends**: FastAPI, Uvicorn, SQLAlchemy, Psycopg2-binary, Pydantic v2, YOLOv8

## Cloud Infrastructure
- **Compute**: Amazon EC2 (Amazon Linux 2023, c6i/t3 instances)
- **Database**: Amazon RDS PostgreSQL (db.t3.micro), SQLite 3 with WAL Mode
- **Storage**: Amazon S3 (Standard Multi-AZ, Server-Side Encryption AES-256)
- **Serverless**: AWS API Gateway, AWS Lambda Functions

## Build & Package Tools
- **Flutter**: Gradle 8.0, Android SDK Build Tools (API 34), Kotlin 1.9.0
- **Python**: Conda (trellis2 env), Virtualenv (env), Pip 24.0+
