# Technology Stack

## Programming Languages
- Python - Version 3.x - Primary language for application logic
- C++ - For performance-critical PCL/Open3D operations

## Frameworks
- Open3D - 3D vision and geometry processing
- Point Cloud Library (PCL) - Advanced 3D processing
- TensorFlow/PyTorch (optional) - ML-based weight estimation

## Infrastructure
- Intel RealSense depth camera - For 3D body capture
- Cloud platform (AWS/Azure/GCP) - For data storage and analytics
- Windows Subsystem for Linux (WSL) - For server-side processing

## Build Tools
- pip - Python package manager
- CMake - C++ build system (for PCL)
- Make - Build automation

## Testing Tools
- pytest - Python unit testing
- Custom validation scripts for 3D mesh accuracy
