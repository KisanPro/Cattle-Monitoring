# Technology Stack

## Programming Languages
- **Python** - `3.11.x` - Core backend, machine learning, dataset pipeline, and REST API.
- **JavaScript (ES6)** - Client-side UI interaction in webapp dashboard.
- **HTML5 / CSS3** - Responsive Kisan Pro user interface layout.

## Frameworks & Libraries
- **PyTorch (`torch`)** - `2.x+` - Deep learning model training and inference.
- **Torchvision** - `0.15+` - Pre-trained MobileNetV3-Small backbone features.
- **Flask** - `3.x+` - Lightweight WSGI web application server.
- **OpenCV (`opencv-python`)** - `4.x+` - Computer vision preprocessing, Gaussian Pyramid downsampling, and keypoint drawing.
- **scikit-learn** - `1.x+` - `ExtraTreesRegressor` ensemble model.
- **Pandas** - `2.x+` - Dataset metadata indexing and prediction reporting.

## Infrastructure & Hardware Execution
- **CUDA Acceleration** - `Nvidia GPU (CUDA 12.x)` - High-speed PyTorch model training and keypoint inference.
- **Local Filesystem Storage** - Structured image datasets (`PNG` / `JPG`) and persistent JSON database.
