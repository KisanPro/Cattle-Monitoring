# Cattle Collar Sensor Module — Multi-Level Evaluation Logs & Outputs

This directory contains experimental records, test results, video stream captures, and telemetry logs across the three stages of Cattle Collar Sensor deployment:

* **Level 1 — Lab Environment**: Laboratory hardware simulation, sensor calibration, accelerometer/gyroscope raw signal plots, and firmware unit test validation.
* **Level 2 — Lab Real-Time Environment**: Live Edge transmission testing, Bluetooth/LoRa telemetry parsing, and companion mobile app real-time stream ingestion.
* **Level 3 — Field Real-Time Environment**: On-field commercial cattle shed deployment records, continuous telemetry logs, battery performance profiles, and multi-animal tracking metrics.
