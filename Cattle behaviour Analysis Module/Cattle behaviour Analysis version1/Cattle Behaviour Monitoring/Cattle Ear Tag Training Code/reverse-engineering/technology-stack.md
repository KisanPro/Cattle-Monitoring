# Technology Stack

## Programming Languages
- **Python** — `3.9+` — Primary implementation language for core logic, deep learning inference, image processing, and CLI runners.

## Frameworks & Deep Learning Engines
- **Ultralytics YOLO** — `>=8.0.20` — Object detection framework for ear tag localization.
- **EasyOCR** — `>=1.7.0` — Deep learning character recognition engine for text extraction.
- **PyTorch (`torch`)** — `>=2.0.0` — Deep learning computational backend and GPU acceleration.
- **TorchVision (`torchvision`)** — `>=0.15.0` — Vision utilities and transformation operators.
- **OpenCV (`opencv-python`)** — `>=4.8.0` — Image I/O, resizing, CLAHE contrast equalization, and visual rendering.
- **Pandas (`pandas`)** — `>=2.0.0` — Tabular data formatting and CSV report export.
- **NumPy (`numpy`)** — `>=1.23.0` — Matrix and image tensor manipulation.
- **PyYAML (`pyyaml`)** — `>=6.0` — Configuration file serialization and parsing.

## Infrastructure & Runtime
- **CUDA Toolkit / cuDNN** — GPU acceleration support for real-time model inference.
- **Cross-Platform OS Support** — Windows, Linux, and macOS compatible.

## Build & Environment Management
- **pip** / **virtualenv** / **conda** — Standard package management.

## Testing & Quality Tools
- **argparse** — Native CLI argument parsing and validation.
- **tqdm** — Real-time progress monitoring.
