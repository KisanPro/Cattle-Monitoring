# Pre-trained Model Weights

Due to GitHub file size limits and large model checkpoint files (.pt and .pth formats), the pre-trained weights for the Cattle Behaviour models are hosted securely on Google Drive.

You can download the model weights from the following link:
* **[Download Model Weights on Google Drive](https://drive.google.com/drive/folders/1Zq08Kh58-XeS0arWaTIPz8PgqU2mj1iH?usp=drive_link)**
