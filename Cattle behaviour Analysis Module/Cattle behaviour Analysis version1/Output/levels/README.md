# Multi-Level Experimental Evaluation & Output Logs

This directory contains evaluation records, test results, video stream captures, and inference output visualizations across three stages of system deployment:

* **Level 1 — Lab Environment**: Initial simulated laboratory environment setup, anomaly detection test benches, training curves, confusion matrices, and camera mounting verification.
* **Level 2 — Lab Real-Time Environment**: Live Edge AI inference testing on NVIDIA Jetson devices connected to real-time CCTV feeds within the testing shed.
* **Level 3 — Field Real-Time Environment**: On-field deployment tests across commercial cattle sheds with live multi-camera monitoring.
